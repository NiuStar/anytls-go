# v0.0.29

## 一键安装交互

- 普通命令仅需 `sudo ./anytls-install_server.sh --install`：从检测到的公网 IPv4／IPv6 中选择 IP，再输入代理端口；自动组合节点地址并生成已验证的私有订阅链接。
- 无需手填 `--addr`、密码、域名或证书。菜单安装与 `--install` 使用同一订阅流程。
- 保留自动化 `--public-ip`、`--port`、`--listen`；无 TTY 不等待选择输入。旧 `--addr` 继续兼容，不作为交互安装前提。
- 保留既有密码、证书和订阅 token；同值配置不重写。订阅 HTTPS 默认 TCP443，与代理端口分离，冲突在写入配置前拒绝。
- IPv6 规范形式与服务端一致；默认／端口快捷绑定适配 IPv6，显式绑定不被覆盖。

## 验证与边界

16 项真实 Bash 编排回归、独立 IPv6 规范表示 oracle、真实 PTY 交互和 Mac 原有 Go 全套／vet 已验证；下载、systemd 在安装器测试中使用明确替身，不声称已在用户公网服务器完成安装。

修复过程中保留了原始 Mac CI 失败：旧 Bash 空数组和中文提示原始字节的测试适配问题均使用新提交修正，未跳过断言。最终发行提交仍须分别通过分支／main CI 和 Release 构建，公开资产另行读回。

公网出口探测不证明入站可达；需放行代理端口和订阅 HTTPS 端口。固定证书／公钥信任不是无条件跳验，私有订阅链接是凭据。
