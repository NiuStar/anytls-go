# v0.0.28 — Public-IP private subscription

Release target: **v0.0.28**. These are release-preparation notes, not a claim that
this tag, its assets, branch CI, or a production deployment already exists.

## Changes

- Add an independent, token-authenticated HTTPS subscription listener. A public
  numeric IP and a persistent self-signed certificate are sufficient; no domain,
  ACME, reverse proxy, or manual CA distribution is required.
- The Linux/systemd installer configures the subscription, restarts its service,
  and verifies the local active certificate and exact node content before
  announcing a private import link. Public-IP discovery is bounded HTTPS;
  failure requires an explicit `--public-ip` override.
- Preserve existing password, persistent TLS material, listen settings and token
  unless explicitly changed. A port bind failure aborts server startup.
- Retain prior control-plane protections, restrictive credential permissions,
  password-file systemd startup, installer checksum verification, TLS/auth
  hardening, sandboxing, and direct `anytls://` certificate-pin verification.

## One-command Linux installation

**Run only after v0.0.28 is published and is the latest stable release.** The
installer resolves the latest stable binary, so fetching a tagged script alone
would not select a tagged binary. No local Go compiler is required.

```bash
curl -fsSL https://github.com/NiuStar/anytls-go/releases/latest/download/anytls-install_server.sh -o anytls-install_server.sh && sudo bash ./anytls-install_server.sh --install
```

For NAT or multiple public addresses, append `--public-ip YOUR_PUBLIC_IP`.
Default ports are AnyTLS TCP **8443** and subscription HTTPS TCP **443**;
open both in host/cloud firewalls. Use `--subscription-listen :9443` to change
only the HTTPS port. The installer intentionally restarts its systemd service.
Local readiness does not prove public-internet reachability.

The printed private link is a credential. Transfer it only through a trusted
channel to a compatible client implementing the bootstrap certificate pin;
ordinary HTTPS subscription importers are not necessarily compatible. The URL
fragment pins leaf DER SHA256 before sending the token (pin-only authentication,
not PKIX plus pin). The node's `certificate-public-key-sha256` instead pins leaf
SPKI with standard base64. Certificate changes require explicit redistribution
of the link; do not disable TLS verification. No private link belongs in Git,
release notes, screenshots, or logs.

See [the subscription operation and trust contract](../private_subscription.md).

## Release and verification boundaries

The existing release pipeline retains its test-before-build and Linux/amd64
smoke gates. Packaging is unchanged: 16 platform binary archives, four installer/
manager scripts, and `checksums.txt`. The three client-manager assets retain the
existing v0.0.23 source; this is not a claim that they implement the new bootstrap.
Branch/PR CI adds Linux and macOS Go 1.26.8 tests, vet, and server-installer Bash
syntax checks. Declaring these gates does not assert a completed CI run.

Public tag creation, CI success, release upload, exact asset/checksum readback,
and installation on an operator-authorized server remain separate release gates.
An updated script cannot add subscription support to an older released binary.
